# Dictionnaire
| Variable | Type | Unité / signification |
|---|---|---|
| Pays | Texte | Nom du pays |
| CodePays | Texte | Code à trois lettres |
| Annee | Entier | 2000–2024 |
| Eau_pct | Décimal | % de population utilisant au moins un service élémentaire d’eau potable, échelle 0–100 |
| Assainissement_pct | Décimal | % de population utilisant au moins un service élémentaire d’assainissement, échelle 0–100 |

Dans comparaison_2000_2024.csv, les suffixes 2000/2024 indiquent l’année. Les variations _points sont des différences de couvertures ; les variations _relative_pct sont des pourcentages relatifs sur échelle 0–100. Ecart = eau − assainissement. VariationEcart = écart final − initial.
